# Chrome Web Store listing (日本語)

Bản tiếng Nhật cho trang cửa hàng. Trên Developer Dashboard, ở **Store listing**, chọn ngôn ngữ **日本語** rồi dán phần dưới vào ô **Description**. Tên và mô tả ngắn đã có sẵn trong `_locales/ja/messages.json`.

## Description

```text
Facebook リールには画質の設定がありません。解像度は Facebook が勝手に決めるため、回線が速くてもリールが 540p や 360p に下がってぼやけることがよくあります。Reel Quality は、見ているリールの上に小さな画質ボタンを追加します。HD 1080p、720p など、動画が用意している解像度を自分で選べます。

🛠️ 使い方
facebook.com で好きなリールを開き、動画上の歯車ボタン (⚙) をクリックします。メニューには、そのリールが対応している画質がそのまま表示されます (例: 1080p、720p、540p、360p)。どれかを選ぶと、すぐにその解像度に切り替わります。Facebook の標準設定に戻すには「自動」を選びます。

✨ 主な機能
• 本物の画質だけ: メニューに出るのは、リールに実際にあり、ブラウザで再生できる解像度だけ。見せかけの拡大や架空の数値はありません。
• 選んだ画質を記憶: 選んだ解像度は次のリールにも自動で適用されます。その解像度がないリールでは、いちばん近い下の画質を使います。
• 横長クリップを拡大: 多くのリールは、実は黒帯と字幕付きの縦長フレームに横長のクリップをはめ込んだものです。Reel Quality はそのクリップを見つけ、利用できる最高画質で画面中央に大きく表示します。
• 音声付きでリールを保存: Facebook の「いいね！」ボタンのすぐ上に「保存」ボタンが表示されます。画質を選ぶと (おおよそのファイルサイズも表示)、リールが音声付きの MP4 ファイル 1 つとしてパソコンに保存されます。映像と音声はブラウザの中で結合され、どこにもアップロードされません。ダウンロード中にもう一度ボタンを押すと中止できます。
• 実際の解像度がわかる: 「自動」のときは、Facebook が今再生している解像度がボタンに表示されます (例: 「自動 · 540p」)。画質が落ちたらすぐに気づけます。
• 視聴中は自動で隠れる: 数秒たつとボタンが消えて動画を邪魔せず、マウスを動かすとすぐに戻ります。メニューでオフにもできます。
• キーボードショートカット: Q でメニュー、Shift + ↑ / Shift + ↓ で画質の上げ下げ、A で自動に戻す、E で横長クリップを拡大、D で保存メニューを開きます。コメント入力中や検索中は反応しません。
• ボタンは移動可能: 動画上の好きな場所にドラッグするか、メニューの 8 つの定位置から選べます。リールを切り替えても、ウィンドウサイズを変えても、全画面にしても位置はそのままです。
• なめらかな再生: 音声、操作ボタン、ループ、シークはこれまでどおり Facebook のプレーヤーが担当します。新しい画質の読み込み中に画面が真っ黒になることはありません。
• 20 言語に対応 (日本語、英語、韓国語、中国語、スペイン語、ポルトガル語、ベトナム語など): 表示言語は Facebook アカウントの言語に合わせて切り替わります。
• 軽くて安全: ポップアップなし、登録なし、複雑な設定画面もありません。

🔒 プライバシーとセキュリティ
Reel Quality はユーザーのデータを一切収集しません。分析ツールやトラッカー、独自のサーバーもありません。特別な権限は求めず、facebook.com でのみ動作し、動画は Facebook 自身の動画サーバーからのみ読み込みます。選んだ画質、ボタンの位置、表示設定はブラウザ内にだけ保存されます。保存したリールはブラウザの中で組み立てられ、そのままパソコンに保存されます。
```

# Chrome Web Store listing (中文（简体）)

Bản tiếng Trung (giản thể) cho trang cửa hàng. Trên Developer Dashboard, ở **Store listing**, chọn ngôn ngữ **中文（简体）** rồi dán phần dưới vào ô **Description**. Tên và mô tả ngắn đã có sẵn trong `_locales/zh_CN/messages.json`.

## Description

```text
以高清画质连声音一起下载 Facebook 视频和 Reels，并用你想要的画质观看。Facebook 既没有下载按钮，也没有画质设置：分辨率由它替你决定，即使网速很快，Reels 也经常降到 540p 或 360p，看起来一片模糊。Reel Quality 在“赞”按钮正上方加一个“下载”按钮，并在视频上加一个小小的画质按钮，让你自己决定：HD 1080p、720p，或 Reel 提供的任何一档。

📥 高清下载 FACEBOOK REELS
点击“赞”上方的“下载”，选择画质（1080p、720p、540p…，每档都显示预计文件大小），Reel 就会以一个带画面和声音的 MP4 文件保存到你的电脑。无水印、不重新编码：你得到的就是 Facebook 播放的原视频，画质由你选。这是直接内置在页面里的 Facebook Reels 和视频下载工具，无需把链接粘贴到其他网站。

🛠️ 使用方法
1. 在 facebook.com 上打开任意 Reel。
2. 想保存：点击“赞”上方的“下载”，然后选择画质。按 D 键也能打开同一个菜单。
3. 想看高清：点击视频上的齿轮按钮 (⚙)，然后选择分辨率。选择“自动”即可恢复 Facebook 的默认设置。

✨ 主要功能
• 连声音一起保存 Reels：Facebook 的“赞”按钮正上方会出现一个“下载”按钮。选择画质（会显示预计的文件大小），Reel 就会以一个带声音的 MP4 文件保存到你的电脑。画面和声音在你的浏览器中合并，不会上传到任何地方。下载过程中再点一次按钮即可取消。
• 只有真实画质：菜单只列出 Reel 实际拥有、且你的浏览器能播放的分辨率。没有虚假放大，没有编造的数字。
• 记住你的选择：你选的分辨率会自动应用到之后的 Reels。如果某个 Reel 没有这一档，就使用最接近的较低画质。
• 放大横屏片段：很多 Reels 其实是把横屏片段放进带黑边和字幕的竖屏画框里。Reel Quality 会识别出这段画面，并以可用的最佳画质在屏幕中央放大显示。
• 看到真实分辨率：在“自动”模式下，按钮会显示 Facebook 当前播放的确切分辨率（例如“自动 · 540p”），画质一下降你就能马上发现。
• 观看时自动隐藏：按钮几秒后会淡出，不遮挡视频；一移动鼠标就会重新出现。可在菜单中关闭。
• 键盘快捷键：Q 打开菜单，Shift + ↑ / Shift + ↓ 提高或降低画质，A 回到自动，E 放大横屏片段，D 打开下载菜单。输入评论或搜索时快捷键不会触发。
• 按钮可移动：把按钮拖到视频上的任意位置，或在菜单中选择 8 个预设位置之一。切换 Reel、调整窗口大小或全屏时，位置都保持不变。
• 播放流畅：声音、控制按钮、循环播放和拖动进度仍由 Facebook 自己的播放器处理。加载新画质时绝不会出现黑屏。
• 支持 20 种语言，包括简体中文、繁体中文、英语、日语、韩语、西班牙语和越南语：界面语言跟随你的 Facebook 账号语言。
• 轻巧安全：没有弹窗，无需注册，没有复杂的设置页面。

❓ 常见问题
• 免费吗？完全免费，无需注册，没有广告。
• 有水印吗？没有。MP4 是 Facebook 的原始画面和声音，在你的浏览器中合并而成。
• 文件保存在哪里？保存在浏览器平常的下载文件夹，文件名类似 reel-123456789-1080p.mp4。
• 会上传任何东西吗？不会。扩展程序只从 Facebook 自己的服务器获取视频。

🔒 隐私与安全
Reel Quality 不收集任何用户数据。没有统计分析、没有追踪器，也没有自己的服务器。扩展程序不申请任何敏感权限，只在 facebook.com 上运行，并且只从 Facebook 自己的视频服务器加载视频。你选择的画质、按钮位置和显示选项只保存在你的浏览器本地。下载的 Reels 在浏览器中合成后直接保存到你的电脑。
```

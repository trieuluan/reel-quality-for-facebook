# Chrome Web Store listing (中文（繁體）)

Bản tiếng Trung (phồn thể) cho trang cửa hàng. Trên Developer Dashboard, ở **Store listing**, chọn ngôn ngữ **中文（繁體）** rồi dán phần dưới vào ô **Description**. Tên và mô tả ngắn đã có sẵn trong `_locales/zh_TW/messages.json`.

## Description

```text
Facebook Reels 沒有畫質設定。解析度由 Facebook 替你決定，即使網路很快，Reels 也常常掉到 540p 或 360p，看起來一片模糊。Reel Quality 會在你正在看的 Reel 上加一個小小的畫質按鈕，讓你自己選擇解析度：HD 1080p、720p，或影片提供的任何一檔。

🛠️ 使用方式
在 facebook.com 上開啟任一 Reel，點擊影片上的齒輪按鈕 (⚙)。選單會準確列出這個 Reel 支援的畫質（例如 1080p、720p、540p、360p）。選一個，影片就會立刻切換到該解析度。選擇「自動」即可回到 Facebook 的預設設定。

✨ 主要功能
• 只有真實畫質：選單只列出 Reel 實際擁有、而且你的瀏覽器能播放的解析度。沒有假的放大，沒有捏造的數字。
• 記住你的選擇：你選的解析度會自動套用到之後的 Reels。如果某個 Reel 沒有這一檔，就使用最接近的較低畫質。
• 放大橫向片段：很多 Reels 其實是把橫向片段放進有黑邊和字幕的直式畫框裡。Reel Quality 會找出這段畫面，並以可用的最佳畫質在螢幕中央放大顯示。
• 連聲音一起儲存 Reels：Facebook 的「讚」按鈕正上方會出現一個「下載」按鈕。選擇畫質（會顯示預估的檔案大小），Reel 就會以一個有聲音的 MP4 檔儲存到你的電腦。畫面和聲音在你的瀏覽器中合併，不會上傳到任何地方。下載中再點一次按鈕即可取消。
• 看到真實解析度：在「自動」模式下，按鈕會顯示 Facebook 目前播放的確切解析度（例如「自動 · 540p」），畫質一掉你馬上就會發現。
• 觀看時自動隱藏：按鈕幾秒後會淡出，不擋住影片；一移動滑鼠就會再出現。可在選單中關閉。
• 鍵盤快捷鍵：Q 開啟選單，Shift + ↑ / Shift + ↓ 提高或降低畫質，A 回到自動，E 放大橫向片段，D 開啟下載選單。輸入留言或搜尋時快捷鍵不會觸發。
• 按鈕可移動：把按鈕拖到影片上的任何位置，或在選單中選擇 8 個預設位置之一。切換 Reel、調整視窗大小或全螢幕時，位置都會維持不變。
• 播放流暢：聲音、控制按鈕、循環播放和拖曳進度仍由 Facebook 自己的播放器處理。載入新畫質時絕不會出現黑畫面。
• 支援 20 種語言，包括繁體中文、簡體中文、英文、日文、韓文、西班牙文和越南文：介面語言會跟著你的 Facebook 帳號語言。
• 輕巧安全：沒有彈出視窗，不必註冊，沒有複雜的設定頁面。

🔒 隱私與安全
Reel Quality 不收集任何使用者資料。沒有統計分析、沒有追蹤器，也沒有自己的伺服器。擴充功能不要求任何敏感權限，只在 facebook.com 上執行，而且只從 Facebook 自己的影片伺服器載入影片。你選擇的畫質、按鈕位置和顯示選項只儲存在你的瀏覽器中。下載的 Reels 在瀏覽器中組合後直接儲存到你的電腦。
```

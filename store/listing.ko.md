# Chrome Web Store listing (한국어)

Bản tiếng Hàn cho trang cửa hàng. Trên Developer Dashboard, ở **Store listing**, chọn ngôn ngữ **한국어** rồi dán phần dưới vào ô **Description**. Tên và mô tả ngắn đã có sẵn trong `_locales/ko/messages.json`.

## Description

```text
Facebook 릴스에는 화질 설정이 없습니다. 해상도를 Facebook이 알아서 정하기 때문에, 인터넷이 빨라도 릴스가 540p나 360p로 떨어져 흐릿하게 보이는 일이 많습니다. Reel Quality는 지금 보고 있는 릴스 위에 작은 화질 버튼을 추가해, HD 1080p, 720p 등 영상이 제공하는 해상도를 직접 고를 수 있게 해 줍니다.

🛠️ 사용 방법
facebook.com에서 아무 릴스나 열고 영상 위의 톱니바퀴 버튼(⚙)을 클릭하세요. 메뉴에는 그 릴스가 지원하는 화질이 정확히 표시됩니다(예: 1080p, 720p, 540p, 360p). 하나를 고르면 영상이 바로 그 해상도로 바뀝니다. Facebook 기본 설정으로 돌아가려면 "자동"을 선택하세요.

✨ 주요 기능
• 진짜 화질만: 메뉴에는 릴스에 실제로 있고 브라우저에서 재생할 수 있는 해상도만 표시됩니다. 가짜 업스케일링이나 지어낸 숫자는 없습니다.
• 선택 기억: 고른 해상도가 다음 릴스에도 자동으로 적용됩니다. 해당 해상도가 없는 릴스에서는 가장 가까운 낮은 화질을 사용합니다.
• 가로 클립 크게 보기: 많은 릴스가 사실은 검은 띠와 자막이 있는 세로 프레임 안에 가로 클립을 넣은 형태입니다. Reel Quality가 그 클립을 찾아 가능한 최고 화질로 화면 가운데에 크게 보여 줍니다.
• 소리까지 담아 릴스 저장: Facebook의 좋아요 버튼 바로 위에 저장 버튼이 생깁니다. 화질을 고르면(예상 파일 크기도 표시) 릴스가 소리가 포함된 MP4 파일 하나로 컴퓨터에 저장됩니다. 영상과 소리는 브라우저 안에서 합쳐지며 어디에도 업로드되지 않습니다. 다운로드 중에 버튼을 다시 누르면 취소됩니다.
• 실제 해상도 확인: "자동"일 때 버튼에 Facebook이 지금 재생 중인 해상도가 그대로 표시되어(예: "자동 · 540p") 화질이 떨어지면 바로 알 수 있습니다.
• 시청 중 자동 숨김: 몇 초 뒤 버튼이 사라져 영상을 가리지 않고, 마우스를 움직이면 바로 다시 나타납니다. 메뉴에서 끌 수 있습니다.
• 키보드 단축키: Q로 메뉴 열기, Shift + ↑ / Shift + ↓로 화질 올리기·내리기, A로 자동으로 돌아가기, E로 가로 클립 확대, D로 저장 메뉴 열기. 댓글을 쓰거나 검색하는 중에는 단축키가 작동하지 않습니다.
• 버튼 위치 이동: 버튼을 영상 위 원하는 곳으로 끌어다 놓거나, 메뉴의 8가지 위치 중 하나를 고르세요. 릴스를 넘기거나 창 크기를 바꾸거나 전체 화면으로 봐도 위치가 유지됩니다.
• 끊김 없는 재생: 소리, 컨트롤, 반복 재생, 탐색은 그대로 Facebook 플레이어가 처리합니다. 새 화질을 불러오는 동안 화면이 검게 변하지 않습니다.
• 한국어, 영어, 일본어, 중국어, 스페인어, 포르투갈어, 베트남어 등 20개 언어 지원: 화면 언어는 Facebook 계정 언어를 따라갑니다.
• 가볍고 안전: 팝업 없음, 가입 없음, 복잡한 설정 페이지 없음.

🔒 개인정보 및 보안
Reel Quality는 사용자 데이터를 전혀 수집하지 않습니다. 분석 도구나 추적기, 자체 서버도 없습니다. 민감한 권한을 요청하지 않으며 facebook.com에서만 작동하고, 영상은 Facebook 자체 동영상 서버에서만 불러옵니다. 선택한 화질, 버튼 위치, 표시 옵션은 브라우저에만 저장됩니다. 저장한 릴스는 브라우저 안에서 만들어져 바로 컴퓨터에 저장됩니다.
```
